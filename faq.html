Frequently Asked Questions

Find answers about ORYX Modding Studios, downloads, compatibility and modding projects.

What is ORYX Modding Studios?

ORYX Modding Studios is an independent MotoGP modding studio focused on creating paint kits, custom liveries, mods and tutorials for the modding community.

Which games are supported?

Each project contains its own compatibility information. Supported games and versions are always listed on the download page.

Are ORYX downloads free?

Most ORYX projects are released for the community and can be downloaded through the official Downloads section.

How do I install a Paint Kit or Mod?

Installation instructions will be available on each project page, including required files and compatibility information.

Can I use ORYX projects in my own creations?

Yes, but always respect the project rules and credits provided by ORYX Modding Studios.

How can I report a problem?

Use the Report Bugs page and provide details about the issue, including the game version and the installed project.
