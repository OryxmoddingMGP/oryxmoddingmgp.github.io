## 🌐 About ORYX

ORYX Modding Studios is an independent Brazilian solo studio focused on creating high-quality content for the MotoGP modding community.

Our mission is to make customization easier through:

- 🎨 Professional Paint Kits
- 🏍️ Custom Motorcycle Liveries
- 📚 Modding Tutorials
- 🛠️ Community Resources

Built with passion for racing and creativity.

---

## 🏁 Projects

### 🎨 ORYX Paint Kits
